# nihar.works
# Policy: open to search, answer engines, user-requested fetches and training.
#
# With an allow-all policy the named groups below change nothing functionally.
# They exist so one bot can be flipped without touching the others, and so the
# intent is legible. To opt out of training: set ai-train=no and change the
# training group's `Allow: /` to `Disallow: /`. Search and user-fetch bots stay
# allowed either way. Never disallow /_next/: crawlers need the CSS and JS to
# render. /api/ holds dev-only tools; /csp-report is a POST-only report sink.
# Disallow lines come BEFORE `Allow: /` on purpose: Google resolves by longest
# match, but first-match parsers (Python's robotparser, some smaller bots)
# would let `Allow: /` win and ignore every Disallow after it.

User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=yes
Disallow: /api/
Disallow: /csp-report
Allow: /
